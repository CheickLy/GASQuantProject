# Grover's Algorithm Simulation

Implemented Grover's Search Algorithm using Python and Qiskit.

## Technologies
- Python
- Qiskit
- AerSimulator
- VS Code

## Key Results
- Simulated 2–22 qubits
- Achieved near-perfect success probability
- Observed exponential runtime growth during classical simulation

## Reference
Thorvaldson et al. (2025) - Grover's Algorithm in a Four-Qubit Silicon Processor
